Conexión de este dispositivo

Se guarda solo en este navegador. Hazlo una vez en cada móvil u ordenador.

Acceso con contraseña

Permite entrar desde cualquier dispositivo con el enlace «Acceso administradores» de la web pública, escribiendo solo la clave de gestión como contraseña. El token se guarda en el repositorio cifrado con esa clave. Usa una frase larga (4 palabras o más). Vuelve a pulsar si cambias el token o la clave.

Configurar otro móvil

Lo escanean con la cámara del móvil y queda listo, sin escribir nada ni tener cuenta de GitHub.
Solo vender: pantalla sencilla con «Vendido» y «Pedir» (para quien vende puerta a puerta). Gestión completa: igual que esta página.

El código incluye el token y la clave: no lo compartas en grupos ni lo dejes a la vista.

Coste por unidad

Se usa para las ventas nuevas y como valor por defecto en los pedidos. Los precios de venta están en data/stock.json.

Copia de seguridad

Exporta los datos de gestión (descifrados) para guardarlos en tu ordenador, o importa una copia. Importar reemplaza ventas, encargos, pedidos y costes.
